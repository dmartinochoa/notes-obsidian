# Full-Length Practice Exams

This folder contains 5 full-length practice exams for the **AWS Certified Security - Specialty (SCS-C03)** exam.

## Format

- Each exam has **65 questions**, matching the real exam length
- Both **Learn Mode** and **Exam Mode** are available, using the same quiz engine as the topic quizzes
- All questions have a **single correct answer** — note that the real exam includes questions requiring you to select 2 or 3 answers; a future version of these exams will reflect that
- Question difficulty is aimed at **Specialty level** — harder than an Associate exam, but not quite at Professional level, which is roughly where the SCS-C03 sits

## Planned Improvements

- Exam Mode only (no Learn Mode), with the ability to **flag questions for review** before submitting
- Longer scenario-based questions — on the real exam, roughly 30 out of 65 questions had 7–8 sentence scenarios, which this version does not fully replicate yet
- Multi-answer questions to match the real exam format

## Tips from the Real Exam

### Question Strategy

- **Trust your first answer.** Changing answers at review time is rarely beneficial, especially when you are fatigued late in the exam.
- **Always answer before flagging.** If you flag a question for review, still select your best answer before moving on. Never leave a question blank expecting to return to it — you may run out of time or be too tired to think clearly.
- **Do not skim.** After enough practice you may recognize a concept quickly and be tempted to scan the options, but read every option carefully. Distractor options are intentionally close to the correct answer.

### Pacing and Preparation

- **One week before the exam:** aim for one practice exam plus 3–5 topic quizzes per day.
- **On exam day:** the topic quizzes are short enough to review from your phone while waiting to be registered at the testing center.
- The topic quizzes work well in Learn Mode on mobile — useful for study sessions during lunch or before bed.

### GenAI Coverage

The real exam (sat March 2026) did not include GenAI security questions, despite it being listed as new content in SCS-C03. The [`genai-owasp-top10-comprehensive`](../quizzes/genai-owasp-top10-comprehensive.html) quiz covers this area thoroughly if that changes in future sittings.

## ESL Exam Accommodation (+30 Minutes)

If English is not your first language and you are sitting the exam in English, you are eligible for a **30-minute time extension** at no cost. This is worth claiming — even at Specialty level, the long scenario questions make time management important.

**How to request it:**

1. Sign in to [aws.training/Certification](https://aws.training/Certification)
2. Select **Go to your Account**
3. Select **Request Exam Accommodations**, then **Request Accommodation**
4. From the **Accommodation Type** dropdown, select **ESL +30 MINUTES**
5. Select **Create**

The extension applies to all future AWS exams automatically from that point on. Full policy details: [aws.amazon.com/certification/policies/before-testing](https://aws.amazon.com/certification/policies/before-testing/)

## Proctored Online vs. Testing Center

Both options are available. Online proctored exams have been reliable since 2020, but Pearson VUE testing centers are a good alternative if you prefer a controlled environment with fewer distractions at home.
