
| Feature                          | AWS Backup                                                      | Data Lifecycle Manager (DLM)                            | Elastic Disaster Recovery (DRS)                                   |
| -------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| **Primary Purpose**              | Centralized backup management across AWS services               | Automate EBS snapshot & AMI lifecycle policies          | Minimize downtime from ransomware, hardware failure, or disasters |
| **Best For**                     | Enterprise-wide backup governance & compliance                  | EBS/EC2-focused snapshot automation                     | Application-level continuous replication & failover               |
| **Supported Resources**          | EC2, EBS, RDS, Aurora, DynamoDB, EFS, FSx, S3, VMware, and more | EBS volumes, EC2 instances (AMIs), EBS-backed instances | Physical servers, VMware VMs, AWS/other cloud instances           |
| **Cross-Account / Cross-Region** | ✅ Both                                                          | ⚠️ Cross-region snapshots only                          | ✅ Cross-region replication                                        |
| **Recovery Type**                | Point-in-time restore of individual resources                   | Snapshot-based volume/instance restore                  | Full server failover with near-zero data loss                     |
| **RTO**                          | Minutes to hours                                                | Minutes to hours                                        | ✅ Minutes (instances pre-staged)                                  |
| **RPO**                          | Hours (backup schedule frequency)                               | Hours (snapshot frequency)                              | ✅ Seconds to minutes (continuous replication)                     |
| **Continuous Replication**       | ❌ No                                                            | ❌ No                                                    | ✅ Yes                                                             |
| **Failback Support**             | ❌ No                                                            | ❌ No                                                    | ✅ Yes                                                             |
| **Policy Management**            | Backup plans with schedules, retention rules, vaults            | Lifecycle policies tied to resource tags                | Replication settings per server/application                       |
| **Tag-Based Targeting**          | ✅ Yes                                                           | ✅ Yes                                                   | ⚠️ Manual server selection                                        |
| **Compliance & Audit**           | ✅ Strong — Backup Audit Manager, reports                        | ⚠️ Limited — CloudTrail logging only                    | ⚠️ Basic — drill reports, CloudWatch                              |
| **Immutable Backups (WORM)**     | ✅ Vault Lock                                                    | ❌ No                                                    | ❌ No                                                              |
| **Pricing Basis**                | Storage used + restore + cross-region transfer                  | Snapshot storage + cross-region transfer                | Per replicated server/hour + EBS storage + data transfer          |
| **Typical Cost Profile**         | Low–Medium                                                      | ✅ Lowest (snapshot-only)                                | ❌ Highest (continuous replication overhead)                       |
| **Ransomware Protection**        | ✅ Strong (Vault Lock)                                           | ⚠️ Partial                                              | ✅ Strong (point-in-time recovery)                                 |
| **Compliance/Regulatory**        | ✅ Best fit                                                      | ⚠️ Limited                                              | ⚠️ Moderate                                                       |
| **DR Drills / Testing**          | ⚠️ Manual restore needed                                        | ⚠️ Manual restore needed                                | ✅ Non-disruptive drill mode                                       |
| **Hybrid / On-Prem**             | ⚠️ VMware via plugin                                            | ❌ AWS-only                                              | ✅ Physical & VM support                                           |
